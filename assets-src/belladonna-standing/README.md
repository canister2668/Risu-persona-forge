# 벨라도나 페르소나 스탠딩 원본

사용자가 NAI Studio에서 생성하고 남긴 원본 PNG 59장, 50개 씬입니다. 모두 832×1216이며 이미지 변환이나 보정 없이 보존했습니다.

- 폴더: `<종족>/<성별>/<나이대>/<NAI 원본 파일명>.png`
- 종족: human, elf, dwarf, fox, dragon
- 나이대: child, teen, young-adult, middle-aged, elder
- `project.json`: 저장 시점의 NAI Studio 프로젝트. 이미지 파일 자체는 포함되지 않습니다.
- `manifest.json`: 씬·캐릭터·프롬프트·파일 경로·크기·SHA-256 대응표.
- 여러 후보가 남은 씬은 모두 보존했습니다. 대표 이미지가 지정되지 않아 임의로 선택하지 않았습니다.

NAI Studio 복원 시 PNG를 `outs/<프로젝트 이름>/<manifest의 scene>/<원본 파일명>`에 배치해야 프로젝트의 이미지 참조와 연결됩니다.

이 폴더는 원본 보관용입니다. 기존 플러그인 이미지 목록과 배포 버전은 이 업로드에서 변경하지 않습니다.
